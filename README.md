# Labs for the IBM course 'Deep Learning with PyTorch' on Coursera

Deep learning is powering modern AI applications—from image recognition to intelligent systems. Building practical skills in frameworks such as PyTorch enables us to move from theory to real-world implementation.

### Course objectives:

* Implement Softmax regression and understand its application in multi-class classification problems.
* Develop and train shallow neural networks with various architectures.
* Explore deep neural networks, including techniques such as dropout, weight initialization, and batch normalization.
* Gain practical experience with convolutional neural networks, exploring layers, activation functions, and more.
